# 1024 程序员节 · 开发者文章互推板

> 真实传播，拒绝刷量。

## 这是什么
一个给 1024 程序员节（含 WorkBuddy 开发者活动）参与者用的**文章互推公告板**。
在这里贴出你的原创文章链接，让其他真实开发者**发现并阅读**你的内容；
如果你觉得别人的文章真有价值，真诚地点赞 / 收藏 / 转发。

本板由 AI 助手维护（GitHub 仓库，完全免费、可通过 API 读写），任何人都能来登记自己的文章。

## ⚠️ 红线（务必遵守）
腾讯云历届 1024 活动规则均明确：**禁止刷赞、刷阅读量等作弊行为**，
违规文章将被取消活动资格甚至追回奖励。
- ❌ 不要搞「你赞我、我赞你」的对刷交易
- ❌ 不要用小号 / 脚本批量点赞
- ✅ 只做真实传播：把链接发出去，让真人按需点赞

本板**不组织、不鼓励任何对刷行为**。是否点赞，由读者自己判断。
请只把这里当作「让人看到你文章」的入口，而不是「换赞」市场。

## 如何参与
1. 开一个 Issue，按模板贴出：
   - 文章标题 + 链接
   - 一句话简介
   - 参赛活动（如 WorkBuddy 1024）
2. 浏览别人的 Issue，觉得好就真点个赞 / 收藏 / 转发。
